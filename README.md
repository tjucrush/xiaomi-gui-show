# Xiaomi-GUI-Show

本地静态展示页面，包含介绍、视频演示、评测图表、方法架构和案例展示。

- GitHub 仓库：https://github.com/tjucrush/xiaomi-gui-show
- 在线网站：https://tjucrush.github.io/xiaomi-gui-show/

## 文件结构

```text
index.html              项目展示页
style.css               页面样式
script.js               图表、视频、图片放大
assets/figs/            图表资源
assets/videos/          演示视频
assets/logo/            标识资源
scripts/                本地检查与构建
```
